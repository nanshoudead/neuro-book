待定 表单出错的提示怎么放

看“并发数”一行（填了 12，超出 1–8）。三种都给框标红。

推荐“收进图标，悬停显示”：不挤占垂直空间；红框加红色图标离开输入框后仍在，一眼看得出哪一项出了错；原因在悬停或聚焦到输入框时出现，读屏经 aria-describedby 读到。“贴在下沿”离开输入框后只剩红框，不悬停看不到原因，还会盖住下一行的控件；“常显一行”最直白，代价是行高跳动。

待定 层出错的警告放在哪

这一层的设置文件写坏时，整层的控件都停用、显示上一份有效值。警告是关于“这一层”的，不是关于某一页的。

推荐“左栏的标签下面”：出错的是整层，提示就挨着切换层的标签放，切到哪一页都在同一个地方，内容区一点不动；“本作品”那一层坏了时同理标在“本作品”上。“标题右侧”最省地方，但位置和标题区右侧要放的页面操作抢；“底部一条”在有保存栏的页面上会和保存栏撞在一起。

待定 标题区右侧放什么

推荐“页面级操作”：操作挨着它作用的对象。“用户 | 本作品”切的是整个窗口（切了以后每一页都换成那一层），留在左栏才说得清它管全部分区。两种都配合内容区限宽约 720px：默认 960 宽的窗口里内容区本来就只有约 680px，限宽只在把窗口拉宽时起作用，名字和控件不会被拉到两头。

待定 文案、只读与确认框这样改可以吗

圆角要改的规范（nb-ui）：NeuroBook 主题里小确认框（AlertDialog）的圆角从 --radius-dialog 26px 改为 14px，同命令面板锁定 14px 的先例；ui-development-spec 的浮层分级里加一条“叠在另一个窗口上的浮层，圆角不大于底下窗口的圆角”。大的对话框（例如设置窗口本身）不变。

重新设计（2026-10-22，已定：A）

开发者 2026-10-22 要求推翻 t80 以来的画法重新设计，方向在 Notion / Linear 式与 macOS 系统设置式之间选；最难看的是控件位置乱、整体太素没质感，以及小交互与卡片样式不像 NeuroBook（例如左栏条目点下去会缩小、选中项是带描边的卡片）。下面两套用同一份内容，控件是真实的 nb-ui 组件，画布按真实窗口 960×640，NeuroBook 主题浅色（深色下一轮再出）。

两套共同的改法：

  • 控件一律靠右，每行控件的右缘对齐；名字与说明在左。
  • 左栏是列表行，不是按钮：没有描边、点下不缩放，悬停与选中都是半透明叠色（浮层上的高亮规则）；分区按“通用、写作助手、扩展”分组。
  • 页面标题用 NeuroBook 字标的衬线展示字体（与书架标题同一套），这是质感的主要来源。
  • 改过的项在名字后面一个蓝色小圆点，“恢复默认”紧跟在控件后面；本作品单独设值的提示是名字下一行的蓝色小字。
  • 模型服务不再左列表右详情：服务商是一张列表，点进去是下一级页面（左上角返回），保存栏只在下一级页面出现。

已定 选哪一套

开发者的决定（2026-10-22）：A Notion / Linear 式。

推荐 B：分组一眼就是一块，彩色图标与卡片正好补上“太素”；卡片是设计语言允许的“层级 +1”（不透明、比窗口亮一档、圆角比窗口小一圈），不是又一层玻璃。A 更贴近设计语言里浮层内“不给面”的缺省做法，更安静，但素的问题主要只靠标题字体来补。
