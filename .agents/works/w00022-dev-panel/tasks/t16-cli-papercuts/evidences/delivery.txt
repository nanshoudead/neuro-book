三、与计划的偏离
1. sameContent 不比较 files：否则旧记录（无 files）升级后每个产物下一次发布都会多出一版。
2. “--include 的发布 git add 失败后重跑只补交”用例写在 tests/artifacts-write.test.ts 的核心层（gitLockWaitMs 300 + 真实 index.lock），没写在 artifacts-cli：同样是真实锁，免去 CLI 层约 10 秒的等待。用例覆盖面板重算哈希一致、重跑不出新版本、未链接有题页面的题不被取代。
3. invalid_questions 明细：页面标记的问题 message 本身已写“题 <题号>…”，按计划格式再拼会重复。改为明细行 = `<page>:<line>:<column> <message> [<code>]`，并把 nbdev ask 的问题 message 也加上“题 <题号>：”前缀，两类一致（--json 里 ask 的 errors[].details.problems[].message 文字因此变了，code 不变）。
4. reference_outside_artifact 的 details.references 多了 line 字段，供明细行写 `<page>:<line> <target>`。
5. --no-lease 的提交失败路径用真实 pre-commit 钩子拒绝（git_failed）触发，没用 index.lock（不等 10 秒）。
6. 核心选项名为 skipLease；新增导出 CreateOptions、partitionConflicts、ClaimedNumber、artifactFileSet、currentContentHash、resolveReference、versionSeeds 及相关类型。
