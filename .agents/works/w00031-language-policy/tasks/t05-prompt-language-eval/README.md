# 中英文提示词对照评测

## 目标与范围

在 story-qa 上对照基础设施提示词（system reminder、工具说明、工具失败结果）用中文与用英文的效果，结果决定现有英文说明（含命令 `description`）要不要改成中文。

- 固定模型与版本、题集、指标（答对率、输出语言正确率、工具调用正确率、token 数）与阈值，事先写定；
- 领域提示词不变（中文，跟着作品语言）；
- 真实模型测试放 `*.llm.test.ts`，显式运行；缺凭据时记为未验证。

背景：独立设计与三轮审查都没有找到可信的中英文提示词对照研究，三方一致认为改动现有说明前要先评测（见 [t01 证据](../t01-adr/evidences/) 的 omp 第三轮第 3 条、[w00028 t01 证据](../../../w00028-i18n/tasks/t01-requirements/evidences/independent-design.txt) 第 3 节）。改了工具说明，旧会话会因工具快照对不上而不能续跑，这个代价也等评测后一起定。

合同：评测本身行为合同未变。
