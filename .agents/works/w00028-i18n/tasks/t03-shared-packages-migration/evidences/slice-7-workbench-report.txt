== 没迁移的（列给主会话）==
1. 单语中文的运行期文字（原来就只有中文，没有双语表）：
   - Shell 的“没有布局”（noLayout）、命令面板“当前页面没有命令面板”、views 呈现里的 unknownView/unplaced/partial/stale 等占位说明、“外壳当前不可调整”；
   - 各命令返回的 CommandResult.reason，经 failureNotice 到用户眼前。
   这些没有英文版，要写英文并决定键，范围大于“按键迁字面量”。建议优先处理会进通知的 reason。
2. 标题栏菜单 4 个菜单项的 label 保持字面量：commands 插件里 MenuItemDeclaration.label 的类型是 LocalizedText（双语对象），装不下文字引用。建议把它放宽为 Text（动 commands 插件，不属本片）。
3. nb-ui 的 Tabs、QuickPick 等共享组件里写死的文字（读屏名称之类）不在范围，未动；src/ui、src/shared 里没有属于 workbench 的文字。
4. 数据性字符串（命令 id、路径、data-* 值）不是界面文字，未迁。

== 给主会话的决定点 / 没把握的 ==
1. 全角标点粘在代码里：TitleBar 的“：”和“（）”（搜索按钮名“搜索命令（快捷键）”）、ItemStrip 的 aria-label “：”仍由代码拼，未进目录；英文界面下会出现全角括号。
   改法是目录里写整句带参数，需要开发者决定要不要改文字。
2. 旧英文不一致（逐字沿用，未润色）：右栏在 partCommands 写 “Auxiliary Bar”，在 viewCommands 写 “Secondary Side Bar”；“Move to”（viewCommands.pickTarget）与 “Move To”（shell.moveTo）；
   主题命令的“Follow System”与设置项的“System”；“Merge 1 views”单数。
3. 参数与数量处理：端口会截断超长参数（500 字符），palette.commandFailed 的 {title} 等不受影响；container.id 作为标题回退时现在是普通字符串（原来也是），不翻译。
4. PaletteHost 去掉了 locale 选项（面板文字由组件经端口取，宿主不再管语言）：连带改了 projects.test.ts 和 lab-command-scene.ts，都是删一个参数。
5. Lab：MoveViewMenu、ViewSection 的夹具里的示例文字（如“资源管理器”）是样例数据，保留字面量；EditorBreadcrumbs 夹具仍传 locale: "zh-CN"（editor 片的组件，不是我这片的）。
6. 没跑 e2e，也没拍 Lab 截图（改动是文字来源，文字内容与旧字面量逐字相同，由 locales.test.ts 保证）。
