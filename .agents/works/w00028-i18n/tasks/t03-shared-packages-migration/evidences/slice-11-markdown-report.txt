## 设计取舍
- 根组件保留可选的 locale，零件去掉。nb-agent-ui 的端口类型（MarkdownDisplayPortProps、PromptEditorPortProps 等）要求有 locale，agent-ports.typecheck 也要求组件接受它，所以根组件只能放宽为可选。零件不受这条约束，只为取文字的 locale 就去掉了。
- render() 只带端口，不带组件这一级的其它 provide。`instance.provides` 不是 Vue 的公开接口；挂上的组件（MarkdownImage）只读端口，其它东西都经属性传。
- 普通 DOM 上的文字（小块的悬停提示、HTML 卡片的按钮）按画的时候的语言取，不做成响应式，与旧行为相同（旧代码在算 decorations 时取 locale）。图片组件则会跟着端口换语言。
- 端口里取不到本包的键时不兜底：这时返回键名，严格模式的宿主引擎会直接抛错，没有可靠的判据去判断何时该兜底。做法与 nb-agent-ui 相同，Spec 里也写明了“显示键名，由宿主引擎报缺键”。
- markdown 插件的 host.ts 现在经 web/text.ts 引 plugin.ts（descriptor），后者又带进 shared/dialects（typebox）。host.ts 头注释说的“不引语言”仍然成立；但 typebox 会不会让按需加载的小块变重，没有量过。
