# book.info 计数与索引重建的耗时（2026-10-28）

100 章样例书，进程内经 `createStoryApi` 调用，每项取 20 次平均；开发机，没有别的负载。

| 场景 | 耗时 |
|---|---|
| `book.info`，没有修订，索引已缓存 | 8.2 ms |
| `revisions.list`，没有修订 | 8.8 ms |
| `book.info`，30 条修订，索引已缓存 | 8.2 ms |
| `revisions.list`，30 条修订 | 8.0 ms |
| 写入一条修订后的第一次查询（重建索引） | 49 ms |

计划要求每次请求新增耗时不超过 50 毫秒：每次打开索引多读一次修订文件（列目录加读小文件），没有测到可见的增加；写入之后第一次查询要重建索引，是已有的一次性开销（与抽取又提交一章后相同）。
