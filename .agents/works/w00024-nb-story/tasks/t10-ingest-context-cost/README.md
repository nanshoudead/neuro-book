# 长书抽取的单章费用：已有记录命中缓存、只带与本章相关的记录

## 目标与范围

单章抽取费用不随章数线性增长，长书（几百章）的已有记录不超出模型上下文；抽取质量不低于 t06 的回归门槛

合同：改 [`story/ingest.md`](../../../../../docs/specs/story/ingest.md) 的非目标“不控制费用”与输出 4（已有记录列哪些）。

## 当前状态

2026-10-20 完成。计划 [plan.md](plan.md) 开发者已确认（决定见下文）；omp 设计审查 14 条（阻断 1、重要 12、建议 1，[evidences/plan-review.txt](evidences/plan-review.txt)）全部成立，计划已修订。

## 决定

开发者 2026-10-20 在会话里定：

1. decision 模型（Jev 等）召回先搁置，另立后续 Task，到时不只测 Jev。
2. 对象、疑问、时间点、秘密先用简单规则筛。
3. 说法改成挑相关的几十条，由可配置的 LLM 挑（这次用 gpt-6-luna）；挑选方式做成可替换，以后可换 decision 模型（输入输出相同、执行过程不同）。候选先用规则缩小（涉及相关对象、挂在列出的秘密与疑问上的说法，从新到旧到字数上限），不把全量说法塞进去：全量每章增约 700 字，300 章约 21 万字。
4. 数值、秘密都做成按书可关闭，默认开，另立 t11。
5. 不加判分模型；不改图结构。
6. 批准真实模型费用：前 20 章回归三次约 6 元，长书评估约 3 元，每多一轮调整约 9 元，最多三轮。
7. 设计审查 14 条的改法全部同意。
8. 整理不在本 Task：本 Task 只让普通章的请求有界，整理改成增量另立 t12。
9. 挑选说法做成可开关、默认关（缓存命中好时它净增费用）。默认模式下说法也不整 400 条进上下文：先放挂在列出的秘密与疑问上的、不挂对象的说法，再用最近的补到 8,000 字（旧最终稿的 16 次跨章说法引用全保住；只取最近的 8,000 字保住 13 次）。
