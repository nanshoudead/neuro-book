# t32 计划：记录分级（模型先验加程序后验）

## Context

[t28](../t28-graph-tiering/README.md) 的实验和开发者 2026-10-27 的讨论定了方向：

- 模型在抽取当时给**先验**（一般准，黑盒），程序在抽完后算**后验**证据（透明、可核对、不一定准），两者**共存**，合并规则公开；
- 只做 3 级，分类沿用已有的类别（`family`）；
- **主要给人看**：查看器默认折叠 3 级、可展开，每条能看到依据；问答与查询默认是否只用 1、2 级另议；
- t28 的数据：模型两遍标注一致 68%、κ 0.55，标 1 级占 31%；程序分与模型平均级别的 Spearman，说法 0.48、对象 0.38、情节 0.35（模型自己对自己 0.61）；程序标 3 级的说法里模型两遍都当主线必需的只有 3%。脚本 `t28-graph-tiering/scripts/program-tier.ts` 是原型。

依据：[t28 README](../t28-graph-tiering/README.md)；数据格式与查询见 `docs/specs/story/{ingest,queries,viewer,cli-skill,qa}.md`。

## 设计审查与这一版的修订（2026-10-27）

omp（因额度用完只出了 3 条）与 Claude Opus 接着审，共 19 条（阻断 1、重要 15、建议 3），报告见 [omp](evidences/design-review-omp.txt)、[Opus](evidences/design-review-opus.txt)，全部核实成立。这一版相对上一版的主要变化：

1. **不剧透的口径**：等级只依赖（书版本、阅读位置），**不依赖视角**（视角是读者的筛选，防剧透的边界是阅读位置；`tier.explain` 同样只含位置之前的信号）。“伏笔候选”标签只在证据来自位置之前的章时出现，所以不构成剧透。
2. **证据窗口**（Opus O1，实测 P=20 时最近三章 81% 是 3 级）：后验信号要求“后文”有证据，刚读到的章没有后文。新增一个状态“未知”：说法所在章距 P 不足 K 章（K 暂定 5，第 1 片按数据定）时，后验记为“未知”，不当成“没有证据”；合并时按先验原样给级、不打“待证实”，没有先验的给 2 级、不折叠。
3. **去掉分位定级与数值分数**（O3、O14）：没有先验的旧书改用同一张规则表（类别加证据档），不再用 25/40/35 分位，也不再有可比不同尺度的“分数”；规则表可逐格测试。
4. **对象与情节不另算程序等级**（O4、O9、O12）：对象列表沿用人物页已有的“展开次要”规则，不再做等级；情节只有模型先验（有先验才显示色块，旧书的情节不显示）；本 Task 的折叠只对**说法**（人物卡“关于他的”）。这收窄了原计划，已定的界面决定（说法与对象折叠、情节只标色块）因此仍成立，对象沿用既有折叠。
5. **引用只数后写的记录**（O13）：`refs` 只数位置在这条说法所在章**之后**的记录的引用（实测约 113/125 条引用来自同一章，是当章写的）；回响阈值改成相对值（O2）。
6. **问答与命令行的输出不变**（O11）：问答工具的参数去掉 `maxTier`，结果不带等级；命令行默认不带等级，加 `--tiers` 才显示、`--max-tier` 才过滤。问答 Spec 输出 3 加一句。
7. **页形状**（omp #4、O12）：带等级参数的列表页多一个 `tiers: [n1, n2, n3]`（满足其它筛选条件的记录里各级的条数，不随 `limit` 变），`total` 是过滤后的总数，只做稳定过滤、不改原有顺序；“展开次要（N）”的 N 取 `tiers[2]`，展开状态也拿得到。
8. **`tier.explain` 给结构化数据**（O10），文字由界面写，所以和“依据弹出层要说人话”的界面决定不冲突；加 `at` 参数与“记录不存在”的错误。
9. **抽取侧**（O5、O6、O7）：`tier` 值不合法时只丢掉这个字段（记诊断），不丢整条说法；核对与修复替换记录时沿用原先验；改 `rules.md` 牵动所有步骤的系统提示词，回放测试与逐字对照要重录。
10. **验收**（O15）：新增“截断到 P 与全量数据在 P 处结果相同”的不剧透判据、角色视角相同、分页、问答不变、真实模型小抽取的通过标准、依据弹出层第二版静态稿排进切片。
