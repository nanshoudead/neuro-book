## 背景与已定方向

来自 [t28](../t28-graph-tiering/README.md) 的实验和开发者 2026-10-27 的讨论：

- 模型逐条标重要度：中等稳定（κ 0.55）、区分度低（31% 标 1 级），单独不够；
- 程序事后算证据：透明、可核对、能用后文信息（被引用、事件词组在后文回响），说法上和模型的相关 0.48（模型自己对自己 0.61）；
- 开发者定：**先验加后验两者共存**。模型在抽取当时给先验（一般准、黑盒），程序抽完后给后验证据（透明、可核对、不一定准）；合并规则透明（`program-tier.ts` 的 `combine`）；
- 分类沿用已有的类别（family），不新增；重要度不做 5 级，3 级，加“被引用热度”这种程序算的连续值；
- 给人看是主要用途：查看器默认折叠 3 级、可展开，每条能看到依据；问答默认视图可以只用 1、2 级（待定）。

## 要设计的点（尚未做）

2. 抽取：先验放在哪一步标（抽取当章，还是整理步骤），提示词怎么写，给不给“1 级应当是少数”的约束；
3. 后验：哪些信号进（类别、后文回响、被引用、涉及对象热度；情节与对象还没有好信号），抽完与追加章后怎么重算，显示依据的写法；
4. 界面：查看器哪些页默认折叠 3 级、怎样展开、怎样显示“待证实”“伏笔候选”两种合并结果；需要出静态稿放 nbdev 给开发者看；
