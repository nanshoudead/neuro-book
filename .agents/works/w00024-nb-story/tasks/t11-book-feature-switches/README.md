# 按书关闭数值与秘密

导入时可按书关闭数值（状态变动）与秘密，默认都开；关掉后抽取不写、已有记录不列、查看器隐藏对应页面

合同：[`story.ingest`](../../../../../docs/specs/story/ingest.md) 输出 18（另改输出 4、13、15 与“副作用与数据”）、[`story.queries`](../../../../../docs/specs/story/queries.md) 的 `features` 与 F4、[`story.viewer`](../../../../../docs/specs/story/viewer.md) 输出 2、4、8、10、11、12、17、21、31、37、38、[`story.qa`](../../../../../docs/specs/story/qa.md) 输出 3。计划见 [plan.md](plan.md)。
