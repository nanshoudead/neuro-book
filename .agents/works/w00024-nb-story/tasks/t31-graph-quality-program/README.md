# 图质量：程序侧（泛称、无名对象、亲属兜底词、过滤持久化、同心图半径）

## 目标与范围

[t21](../t21-usage-feedback/README.md) 里《老师，男生也能报考魔女学院吗？》那一节的六点反馈，开发者 2026-10-27 确认“按推荐做，先做程序侧”。核实结果与 V7 的参照见 t21 该节。本 Task 只做不调真实模型的部分；合同：[`story.queries`](../../../../docs/specs/story/queries.md)、[`story.viewer`](../../../../docs/specs/story/viewer.md)。

1. **泛称不计出场**：一份泛称词表（学姐、新生、老师、少女、女人……，整个词相等才算）。名字是泛称的称呼不计入出场（`view.mentions`）、不在阅读页里链到对象；只靠它们出场数和同场权重被虚高的现象消失。
2. **无名对象**：可见称呼全是泛称（或没有称呼）的人物、马甲、组织，标 `anonymous`。关系图默认不画它们（`graph.relations` 加 `includeAnonymous`，缺省 false），关系图页有“显示无名角色”开关；对象列表里照列但带标记并排在后面。
3. **亲属兜底词**：一对点的关系词，亲属类说法里找不到亲属词（姐妹、父女……或“亲属、亲人、亲戚、家人”）时不再写“亲属”，往下看社交称谓与所属（“洛萱是星瑕的直系后辈”是师承辈分，不是血亲）。
4. **关系图的过滤刷新后保留**：类别、连线层、同场门槛、排版、只看周边、无名开关存进浏览器偏好（`host/prefs.ts`）。
5. **同心图的半径放大**。

不在本 Task：抽取提示词改动（多问一句马甲与本人、辈分不标亲属、无专名人物的抽取）、用户手工修订层（需要真实模型验证或另立设计）、避免线条重叠的布局（出评审板让开发者选）。
