### 输入事件专项的静态核对

- Sigma `3.0.3` 的鼠标 captor 在 `container` 收 `mousedown`，在 `document` 收 `mousemove`/`mouseup`；它把原生 MouseEvent 留在 `event.original`。右键确实也发 `downNode`，新增 `button > 0` 会挡住该入口；左键原生 mousemove 的 `buttons & 1` 不会被无理由判为松手。没有证据支持“标准浏览器左键拖动会因该判断误停”，不报这种推测。
- 触屏的 `TouchEvent.button` 是 undefined，`undefined > 0` 为 false，因此新增判断不拦触控 down。但组件原本只给鼠标 captor 绑定拖点回调，触控经独立 TouchCaptor：触控拖点缺失和 touchup 不清鼠标状态是 base 已有的边界，不能算本批回归。笔输入仅凭兼容 MouseEvent 语义不能证明特定硬件行为，本次没有笔硬件实测。
- 松手在窗口外时，新增分支只清本组件 `dragged`/`downAt`，没有重置 Sigma 的 `isMouseDown`，返回后 Sigma 仍会按摄像机拖动处理。它消除了“点继续追着鼠标”的本次症状，但不是完整的窗口外手势结束；该相机问题 base 同样存在，单独列为未解决旧边界而不计本批问题。

### 重要｜正确性：隐藏类型后选中浮条仍指向已从画布移除的节点

## 最终影响排序

### 重要（4）

1. **正确性：进入全屏后选中浮条消失。** `RelationsPage.vue:130-136`、`BookGraphPage.vue:87-94`、`StoryNetwork.vue:631-634`。真实 Fullscreen API 只把 `.story-graph` 放入全屏树，兄弟 `SelectionBar` 不在其中；用户在全屏中仍能选点，但看不到名称和打开/取消操作。建议让外层统一进入全屏，或把浮条放入全屏根。
2. **正确性：390px 窄屏浮条遮住全屏按钮并覆盖图例。** `graph/SelectionBar.vue:9-16`、`StoryNetwork.vue:738-765`。真实 390px 场景浮条为 `x=29..361,y=409..451`，全屏按钮为 `x=339..363,y=429..453`；按钮中心命中浮条。建议给底部控件划独立区域或按图容器可用宽度给浮条预留右侧空间。

4. **正确性：ThemeMenu 丢失调用方布局 class。** `parts/ThemeMenu.vue:24`，调用方 `ImportPage.vue:192`、`IngestPage.vue:170`、`SettingsPage.vue:321`。`DropdownMenuRoot` 不渲染 DOM，调用方的 `ml-auto` 不会到触发器；真实浏览器确认按钮没有 `ml-auto`，三个页面的明暗按钮不能按 Spec 的顶部右端布局。建议显式提供 `rootClass`/attrs 转发通道。

### 建议（5）

5. **正确性/事件合同：一次 Dialog 关闭发出两次 `cancel`。** `parts/ModeNotice.vue:36-39`，对照 `nb-ui/Dialog.vue:251-254`。一次取消、Esc 或遮罩关闭会同时触发 `update:model-value(false)` 和 `cancel`，组件各转发一次；当前 `QaPage` 置空是幂等的，但消费者收到的关闭事件数量错误。建议只转发一个关闭来源。
6. **正确性/合同：ModeNotice 缺少 Spec 与同名文档承诺的标题栏关闭按钮。** `parts/ModeNotice.vue:36-39`、`ModeNotice.md:7,24`、`docs/specs/story/viewer.md:124`。`Dialog` 默认 `closable=false`，真实按钮清单只有“先不切换”和倒计时确认键；Esc、遮罩仍可关闭。建议显式启用关闭按钮，或同步删除合同中的承诺并补测试。
7. **公开合同：`RelationNode.names` 变为必填，但公开类型示例和兼容说明未同步。** `contract/contract.ts:336`、`docs/specs/story/queries.md:98-105,190`。真实新 CLI 输出正常，但旧节点按新 schema 校验得到 `/nodes/0 must have required properties names`。建议字段保持可选以保留公开兼容，或同步更新 Spec、发布说明和消费者测试。
8. **文档一致性：组件能力标签和公开类型未反映新增通道。** `parts/ThemeMenu.md:2,15`、`parts/ModeNotice.md:2`、`graph/StoryNetwork.md:24,43`。ThemeMenu 实际共享 `useAppearance`/偏好存储，ModeNotice 使用计时器，NetworkNode 文档没有 `names`；读者按文档无法判断这些接口和资源。建议同步标签、attrs 落点、计时器和别名匹配语义。
9. **测试有效性：别名归属和右键“不位移”用例的断言过弱。** `core/queries/graph.test.ts:45-57`、`e2e/viewer.e2e.ts:169-189`。将实验副本中两个别名来源交换后，核心别名测试仍为 `1 pass、0 fail、6 expect`；右键用例没有先确认抽屉关闭，已有卡片可能让可见性断言通过。建议断言固定实体 id/名称归属，右键场景先清除并确认无卡片，再断言具体卡片。
