# 发布说明草稿：nb-story 0.2.0、nb-runtime 0.2.0、nb-harness 0.1.1

自 0.1.1（nb-story）与 0.1.0（nb-runtime、nb-harness）以来。其余 6 个包没有改动，不重发。

## @notnotype/nb-story 0.2.0

抽取

- 马甲核对（`ingest.personaCheck.enabled`，默认开）：每章提交前对没连上的马甲问一个窄问题，答出同一个人时写一条候选身份说法；泛称加复合词判定（“志愿者学姐”不再被当成名字）。
- 记录等级：抽取时写说法与情节的先验等级，查询给后验与依据，命令行 `--tiers`、`why`，查看器有等级色块、依据弹出层与次要说法折叠。
- 网关出错写得更清楚：413 说明是请求太大并建议换网关；429 按更长的表退避并认 `Retry-After`；同一章失败后可自动重做（`--auto-resume`）；一步两次回复不成形时把原文留在书库的 `bad-replies/`。
- 严格网关拒绝推理档时改发最近的启用档；自定义模型输出上限默认 32768。

图的修订（新）

- 确认或驳回抽取留下的候选身份、手动连两个对象、改对象种类（按位置生效）、把称呼挪给别的对象；修订按书单独保存，不改抽取数据，可撤销。
- 查看器：导航“待确认”页、人物卡头部就地确认、“⋯”菜单与三个对话框；命令行 `nbstory revisions …`。

问答

- 可以读还没抽完的书的未抽取尾部；对话中途可以改阅读位置；问答页有位置控件、会话状态条与上下文检查器；第一次切换读书方式先弹说明。

查看器与命令行

- 网页能导入已抽好的记忆图、删书、装 Skill；关系图有应力排版与“只画最强的线”；设置页与书架有明暗切换；手机宽度可用。
- `nbstory --version`、`config` 的动作级帮助、`config set ingest.model` 三段式写法。

## @notnotype/nb-runtime 0.2.0

- 不兼容：`provide` 改名 `provideService` 等（w00027 t14）；远程调用结果按方法定型（业务失败按码区分），新增 `eventSource` 助手；正常关闭带来的插件撤回只记 debug。

## @notnotype/nb-harness 0.1.1

- 请求里合并相邻的用户消息；完成监视与补全的若干修正。

## 升级须知

- 旧书库照常使用：书库格式不变（仍是版本 1），新增字段都是可选的；旧版本的程序打开新书库时看不到修订、其余照常。
- 抽到一半的书可以接着抽、追加新章；升级前后抽的章规则可能不同（没有记录每章用的规则版本）。
- 不支持原地重抽：删书后重新导入（想保留旧的就换一个书名导入），重抽是新的一代，阅读位置与修订不带过去。
- 已装的 Skill 不会自动更新：`nbstory skill install --force`。
