# PluginsPage

设置窗口里“插件”分区的页面（[`runtime/plugin-install.md`](../../../../../../../docs/specs/runtime/plugin-install.md) 输出 1–4、7–9）：`nbook.plugins` 贡献的 column 页面，只在“用户”标签下可用。列出第三方与内置插件，从服务端上的文件夹安装第三方插件，启用、禁用与卸载它们。所有操作都在下一次启动 NeuroBook 后生效：页面顶部常驻说明，有待生效的变化时每个插件上写出它（例如“重启后启用”）。安装前先预览，确认界面写明是首次安装、升级还是降级，以及完全信任的后果。内置插件标“内置”，没有任何操作。设置窗口画分区的标题与说明，这里从说明横幅开始画。

## 布局

从上到下：

1. 说明横幅（`Banner`）：平时是信息色的“安装、卸载、升级、启用与禁用在下一次启动后生效”；有待生效变化时换成警告色的“有待生效的变化，重启 NeuroBook 后生效”。安全模式下另有一条警告色横幅：“安全模式：第三方插件没有加载，可以在这里禁用或卸载它们”。
2. 安装：标签“服务端上的插件文件夹”，一行输入框（伸缩，占位文字是示例路径）加“安装…”按钮。窄屏时两者仍在同一行，输入框收窄。
3. 失败说明区：常驻的读屏播报区，平时空着、不占高度；操作失败时显示一行原因（危险色），需要时下面接服务端给的详情与出错字段（每条一行，淡色），可在任意处折行。
4. 插件列表，分两组，各有一行小标题（下有分割线）、组内按 id 排序：先“第三方插件”（没有时写“还没有安装第三方插件。”），后“内置插件”。每个插件一行，行与行之间是分割线、不画框：左边是 id、版本与徽标（“内置”；待生效变化，例如“重启后安装”“重启后升级到 1.1.0”；没有登记的原因，例如“清单无效”“不兼容”），清单无效与不兼容时下面另起一行写原因；右边是第三方插件的启用开关与“卸载”按钮。左边的文字与徽标放不下时换行；整行放不下左边约 240px 加右边的控件时，开关与“卸载”换到左边内容的下面、靠右。

列表自己不滚动，由设置窗口的内容列滚动；宽窗口下内容列的宽度由设置窗口封顶。

## 交互

- **安装**：在输入框按 Enter 或点“安装…”。路径为空时只把焦点放进输入框。否则先调 `inspect` 预览（不复制、不写登记表）：
  - 预览失败：在失败说明区写原因，不开确认框；
  - 预览成功：打开确认框，标题按预览是“安装插件”“升级插件”或“降级插件”，正文写插件 id 与版本（升级、降级写“旧版本 → 新版本”）、完全信任的后果（插件可以访问全部作品、服务器与本机资源）与路径；降级另有一句“降级后插件可能读到新版本已迁移过的数据”。
  - 确认后调 `install`，确认按钮显示进行中，结算前对话框保持打开。成功：关闭对话框、清空输入框、重新读列表；失败：关闭对话框，写原因。关闭后焦点回到“安装…”。
- **启用开关**：调 `enable` 或 `disable`。进行中只停用别的写控件，正在操作的开关保持可聚焦，重复切换被忽略；成功后这一行换成返回的新状态。开关的值是登记表里的用户状态（不是本次运行的状态），与“重启后启用”“重启后禁用”徽标一起看。
- **卸载**：打开确认框（“卸载 {id}？重启后删除插件的安装目录，配置与私有数据保留。确认后到重启之前不能撤回。”），确认按钮是危险色、显示进行中；成功后这一行换成“重启后卸载”，开关与“卸载”不再显示，焦点移到“第三方插件”小标题。
- 任一写操作进行中时，别的写控件都停用，不发起第二个写操作。
- 失败码是 `unknown-outcome`、`not-installed`、`uninstall-pending`、`already-installed` 时（列表可能已过时），写出原因之后重新读列表。
- 读取列表失败时原位显示原因与“重试”。
- 键盘：Tab 依次经过输入框、“安装…”、每个第三方插件的开关与“卸载”；开关用 Space 切换；对话框里 Esc 取消。开关的可访问名称是“启用 {id}”，“卸载”是“卸载 {id}”。

## 数据

```ts
import type {DisplayLocale} from "nbook/shared/localized-text";
import type {PluginsRegistry} from "../../shared/contracts";

type Props = {
    /** `nbook.plugins/registry` 合同的六个方法（浏览器入口经 `context.remote.use` 取得的客户端）。必填。 */
    registry: PluginsRegistry;
    /** 显示语言。必填。 */
    locale: DisplayLocale;
};
```

没有 emits、slots、expose；attrs 落在根上。根带 `data-plugins-page` 与 `data-plugins-state`（`loading`、`failed` 或 `ready`）；说明横幅带 `data-plugins-restart`，安全模式横幅带 `data-plugins-safe-mode`；路径输入框带 `data-plugin-path`，“安装…”带 `data-plugin-install`；读取失败的说明带 `data-plugins-load-failure`，其中的“重试”带 `data-plugins-retry`；两组各带 `data-plugin-group`（`third-party` 或 `builtin`），第三方插件为空时的说明带 `data-plugins-empty`；每个插件一行带 `data-plugin-row`（id）与 `data-plugin-source`（`builtin` 或 `third-party`），其中待生效变化的徽标带 `data-plugin-pending`（种类），没有登记的原因带 `data-plugin-not-loaded`（码），开关带 `data-plugin-toggle`，“卸载”带 `data-plugin-uninstall`；失败说明带 `data-plugin-problem`（失败码）。

## 状态

- **加载中**：列表的位置是转圈与“正在读取插件…”（`role="status"`、`aria-busy`），约 200ms 后才出现，读得快时不闪。
- **读取失败**：列表的位置是原因与“重试”（`role="alert"`），不画两组。
- **空**：没有第三方插件时第三方一组只有一句说明；内置插件一组总有内容。
- **进行中**：见“交互”；停用的控件按 nb-ui 的停用外观。
- **安全模式**：安全模式横幅；第三方插件带中性色的“安全模式未加载”徽标，开关与“卸载”照常可用（写登记表，下一次启动生效）。
- **卸载中**：只有“重启后卸载”徽标，没有开关与“卸载”。

## 隐藏通道理由

- `state:local`：列表、读取状态、输入框、两个对话框的开合与预览、进行中的操作与最近一次失败。
- `env:portal`：来自 `Dialog`。

## 注意事项

- 读写都经属性传入的 `registry` 发出，它是调用方给的、可替换的入口，不是组件自己伸出去的通道。
- 失败说明的原因是按失败码的固定文字；服务端的 `detail` 只在它能补充信息时（清单无效、路径不能用、复制失败、缺入口文件、登记表失败、不兼容、路由层失败）作为第二行显示，文件系统错误只带错误码。不认识的码显示“操作没有完成”。

## 不支持

不选择文件夹（只输入服务端上的路径，Desktop 的文件选择器之后接入）；不提供删除私有数据的卸载选项；确认界面不列出升级后会受阻的依赖插件（第三方插件之间的依赖随入口代码的装载实现）；不显示插件入口的运行状态与受阻原因；不提供重启按钮。
