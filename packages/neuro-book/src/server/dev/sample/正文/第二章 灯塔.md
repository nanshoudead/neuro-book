# 第二章 灯塔

灯塔在港口北边的礁石上，退潮时能走过去，涨潮时只能划船。

林汐回到塔里，先去顶层看了一眼灯。透镜擦得很干净，旋转机构转得均匀，每十二秒扫过海面一次。这是父亲留下的习惯：不管心里装着什么事，先看灯。

她在灯室的小桌前坐下，终于拆开了那封信。

信上只有一行字：“第四块礁石下面，还有一盏没点的灯。”

她把这行字读了三遍。雾港外面一共有九块露出水面的礁石，父亲生前给它们都起了名字，记在一本防水的笔记本里。第四块叫“哑巴”，因为浪打在上面从来不响。

笔记本还在书架最下层。林汐翻到写着“哑巴”的那一页，父亲的字迹很潦草：退大潮时可见石缝，内有旧灯座，民国年间所建，已废。

旁边用铅笔补了一句，颜色比别的字浅得多，像是很多年后才加上去的：

“有人还在等它亮。”
