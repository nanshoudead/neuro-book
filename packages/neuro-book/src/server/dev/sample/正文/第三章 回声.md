# 第三章 回声

大潮在第三天的凌晨退到最低。

周砚本来没打算跟来。他在邮局门口等她交还铁皮盒子的钥匙，结果被她塞了一支手电筒，就这么跟着走上了湿漉漉的礁石。

“你知道这样很危险吧。”他说。

“知道。”林汐头也不回，“所以才叫你来。真出了事，总得有人回去报信。”

“我是邮局的，不是报信的。”

“有区别吗？”

周砚被问住了，只好闭嘴，低头看脚下。

“哑巴”比他想的要大，像一头趴在海里的牛。石缝在背海的一面，窄得只能侧身挤进去。林汐先进去，手电光在里面晃了几下，忽然停住。

“周砚。”她的声音在石缝里撞出回声，“你过来看。”

石缝深处果然有一个铁铸的灯座，锈得发黑。灯座旁边整整齐齐码着一摞信封，用油布包着，最上面那封的颜色他再熟悉不过——灰蓝色，没有寄信人。

收信人一栏写着：雾港邮局，周砚。
