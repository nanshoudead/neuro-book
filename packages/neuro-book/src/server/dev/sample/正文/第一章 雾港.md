# 第一章 雾港

雾港的雾是从海面上一层一层爬上来的。先吞掉防波堤尽头那盏红灯，再吞掉码头边的吊车，最后连邮局门口那块掉了漆的招牌也看不清了。

林汐推门进来的时候，周砚正在给一摞旧信盖戳。他抬头看了她一眼，手里的戳子停在半空。

“又是你。”

“又是我。”林汐把围巾往下拉了拉，露出被风吹红的鼻尖，“今天有没有？”

周砚没有马上回答。他把那摞信推到一边，从柜台底下抽出一个铁皮盒子。盒子里只有一封信，信封是灰蓝色的，没有寄信人，收信人一栏写着：灯塔，林家。

“昨天夜里塞进信箱的。”他说，“没贴邮票，也没有邮戳。按规矩，这种信我不该收。”

“那你为什么收了？”

周砚想了想，说：“因为上一封也是这样。”

林汐接过信，没有拆。她把信封翻过来，对着门口那点灰白的光看了很久。纸很薄，能隐约看见里面折了三折的信纸，字迹被折痕压得歪歪扭扭。

“我父亲走了七年了。”她说，“七年里，每到起雾的季节，就会有一封这样的信。”

门外传来雾笛声，低低的，一声接一声，像是有人在海上叹气。
