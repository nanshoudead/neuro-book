# PromptPasteBlockView

`PromptEditor` 正文里的粘贴块：中等大小的粘贴在编辑器里显示成它，文字里是 `<paste id="N">`…`</paste>` 独占的几行。它是 ProseMirror 节点视图，props 由编辑器内核给出，离开 `PromptEditor` 没有可验证的状态，所以在 `PromptEditor` 的 Lab 场景里看。

外框、头部与收起时的预览由纯展示零件 [`PromptPasteFrame`](PromptPasteFrame.md) 画，已发送消息的静态显示用的是同一个零件；本组件往里放可编辑的文本框与“转为文字”“删除”两个按钮。

## 布局与交互

- 独占一段、与正文同宽。头部一行：图标、`#N`、“粘贴的文本 · 42 行”，以及“展开”“转为文字”“删除”三个按钮；下面用等宽字显示内容。
- 超过 3 行的内容默认收起，只显示前 3 行，点“展开”或点这块预览展开；不超过 3 行的不折叠，没有“展开”。展开与否是自己的临时状态。
- 内容完整显示时（展开，或本来不超过 3 行）就是一个可编辑的文本框，外观与预览相同；文本框获得焦点时整块描边换成强调色。只读时只显示，不能编辑，按钮只剩“展开”。
- 编辑：
  - 每次输入都写回粘贴块，进编辑器的撤销历史，连续输入合并成一步。在文本框里按 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z 或 Ctrl+Y，撤销、重做的也是编辑器的历史。
  - 回车换行；Ctrl/⌘+回车发出编辑器的 `submit`。
  - Escape 回到正文，光标落在粘贴块之后。光标在内容开头时按上或左方向键、在内容末尾时按下或右方向键，回到正文里粘贴块的前面或后面。
  - 内容不能有恰好是 `</paste>` 的一行：写回文字时粘贴块会在那里提前结束。出现这样一行时文本框标为无效并给出说明，这次输入不写回；离开文本框时恢复为最后一次写回的内容。
  - 编辑中行数超过 3 行也不收起。
  - 焦点在正文与文本框之间移动不算离开编辑器，编辑器不发 `blur`、`focus`。
- “转为文字”把整块换成同样内容的普通文字（不识别写法），光标落在这段文字末尾；“删除”删掉整块，它的位置标记由编辑器一起删掉。两者都进撤销历史。
- 悬停时与同号的位置标记互相高亮。

## 数据

节点属性见 `prompt-text.ts` 的 `PromptPasteBlockAttrs`；编辑器状态见 `prompt-editor-extensions.ts` 的 `PromptNodeContext`。没有 slot、emit 与 expose。

`state:inject`：界面文字读 `PromptEditor` 提供的翻译端口（Tiptap 的 Vue 节点视图带着编辑器组件的 provide），与编辑器其它部分同一种语言（[README](../../README.md#界面文字)）。
