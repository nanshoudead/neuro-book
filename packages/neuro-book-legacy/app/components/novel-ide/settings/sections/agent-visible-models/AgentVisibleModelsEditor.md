# Agent 可见模型编辑器

给全局配置维护一份有序的模型清单。清单里的模型才是 Agent 能选的模型，顺序会写进提示。留空时运行时回退到当前默认模型，所以空状态要说明回退到哪一个，而不是看起来像没保存。

调用方传入已启用模型、当前默认模型键和清单本身。增删、改用途、上下移动都通过 `update:modelValue` 交回整份新清单。同一模型不能出现两次。超过五条仍可保存，只提示清单变长会增加选择噪音。当前不可用的键留在行上并标出，避免静默丢掉用户已经写过的条目。
