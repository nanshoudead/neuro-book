# AgentModelCatalog

从一份很大的模型目录（OMP 内置目录有六十多家服务商、五千多个模型）里挑几个模型的对话框。左边是服务商，右边是这一家（或全部）的模型表，顶上一个搜索框按 `服务商/模型名` 搜。和普通下拉不同的是它知道服务商“能不能用”：只认环境变量的宿主里，要登录的、用云凭据链的服务商排在分隔线后、变暗，点进去右边是说明页（要设哪个环境变量、是否只能登录、目录里有几个模型），模型不能选。它是纯视图：目录数据、哪些已经选过都由宿主给，选好的引用经 `pick` 交回，宿主写进自己的配置。做法参照 OMP 的 `/models`。

## 布局

- 对话框 `xl`，高 620px。正文左右两栏：左栏 230px，右栏伸缩。
- **左栏**：最上面“全部”，然后能用的服务商（自定义的、密钥有值的在前），每行一个状态圆点（有值绿、没值黄、不用密钥绿）、名称、自定义的标“自定义”、右侧模型数；分隔线后是用不了的服务商，变暗、圆点灰。搜索时右侧的数换成命中数，没有命中的服务商变暗。最下面一个“添加自定义服务商…”按钮。左栏内部滚动。
- **右栏**：顶上搜索框；下面是这一家的标题行（名称、密钥状态、模型数）和模型表。列为：模型（显示名，下面一行等宽字的模型名；在“全部”或搜索时另写服务商）、接口、上下文（`200K`、`1.05M`）、推理（图标）、图片（图标）、单价（每百万 token 的输入 / 输出，未知写“未知”）。行首是复选框。一次最多画 200 行，多了在表尾写“还有 N 个，继续输入缩小范围”。表格区内部滚动，表头不动。
- **页脚**：左边“选中 N 个”，右边“取消”与“加入候选（N）”；没选中时后者不可用。
- **窄**：对话框宽度小于 720px 时先去掉接口列，小于 560px 再去掉推理与图片列；小于 640px 时左栏收成右栏顶上的一个服务商下拉，下拉与搜索框各占一行。`390×844` 下对话框全宽，结构同上。

## 交互

- 点左栏一项切换右栏；点用不了的服务商时右栏是说明页。
- 搜索框输入即过滤（不防抖：排序只在服务商数据变化时做一次，按键时只做匹配；六千个模型的合成目录在 Bun 下排序约 13 毫秒、每次匹配约 3 毫秒）。有查询时右栏不管左栏选了哪家，列出全部服务商里的命中，按精确、连续子串、模糊三层排；左栏仍可点一家只看它的命中。
- 点一行或它的复选框勾选或取消；已经在宿主候选里的（`chosen`）写“已添加”、不能勾；用不了的服务商的模型不能勾，悬停写原因。
- “加入候选”发出 `pick`（勾选的引用，按勾选先后），随后关闭；“取消”、Escape、点遮罩关闭且不发 `pick`。每次打开时清空勾选与查询，焦点在搜索框。

## 数据

```ts
import type {AgentLocale, CatalogProviderView} from "@notnotype/nb-agent-ui";

interface AgentModelCatalogProps {
    /** 必填，受控（v-model:open）。 */
    open: boolean;
    /** 必填：服务商与模型，按宿主想要的顺序；见核心的 model-catalog.ts。 */
    providers: readonly CatalogProviderView[];
    /** 必填：已经在候选里的引用（`服务商/模型名`），显示“已添加”。 */
    chosen: readonly string[];
    /** 必填：界面语言。 */
    locale: AgentLocale;
}

interface AgentModelCatalogEmits {
    (e: "update:open", open: boolean): void;
    /** 点“加入候选”：勾选的引用，至少一个。 */
    (e: "pick", refs: string[]): void;
    /** 点“添加自定义服务商…”。宿主打开自己的表单；本组件不关闭。 */
    (e: "add-provider"): void;
}
```

没有 slot 与 expose；attrs 不透传（落在对话框上会被 Teleport 带走）。

## 状态

- **空目录**：左栏只有“全部”，右栏写“没有匹配的模型”。
- **搜索没有结果**：右栏写“没有匹配的模型”。
- **用不了的服务商**：说明页，见布局。
- 没有加载中与出错：数据由宿主准备好再打开。

## 不支持

- 不读目录、不写配置、不测密钥：都由宿主做。
- 不做“最近用过”：宿主没有这份数据时没有意义。
- 不能改模型的参数（上下文、单价）：自定义服务商的模型在宿主的服务商表单里改。

## 隐藏通道理由

`env:portal` 来自 nb-ui 的 Dialog：对话框渲染到宿主提供的浮层目标（缺省 body）。
