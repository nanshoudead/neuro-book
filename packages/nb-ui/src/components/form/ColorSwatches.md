# ColorSwatches

`ColorSwatches` 是一组可单选的圆形色块，用来从少数几种推荐颜色里挑一个。可以在最前面放一个“自动”（值为 null，颜色交给使用方去推算），在末尾放一个“自定义”（点它在旁边打开取色面板，挑色板以外的颜色）。它适合“作品主题色”这类：大多数人选推荐色或者不选，少数人要精确取色。

## 布局

色块缺省 22px（`sm` 为 18px），间距 8px（`sm` 为 6px）。缺省排成一行、放不下时换行；给了 `columns` 就排成固定列数的网格，网格撑满所在的宽度，多出的宽度均分到列之间（间距不小于上面的值）。选中环在色块外面，放在会裁切的容器里时由容器留出边距。

- 普通色块：整块填色，加一圈很淡的内描边，浅色在浅底上也看得出边界。
- “自动”：给了 `autoColor` 时填这个颜色（使用方推算出来的那一色），中间一个小星星标记；没给时是控件底色加描边。
- “自定义”：还没有自定义色时是控件底色加描边，中间一个吸管图标；当前值不在色板里时整块填这个颜色。
- 选中的色块外面隔一圈底色再画一圈正文色的环；键盘聚焦时画控件的焦点环。
- “自动”“自定义”悬停时用 Tooltip 显示各自的文字。

取色面板（“自定义”打开的那个）从上到下是：饱和度与明度面、色相条、颜色值输入框。

## 交互

- 点击或按空格选中一个色块，发出它的颜色；选中“自动”发出 null。再选当前已选的色块不发事件。
- 选中“自定义”不改值，而是在它下方打开取色面板；在面板里取的颜色立即发出。面板打开期间“自定义”的 Tooltip 不显示。点面板外面或按 Escape 关闭。
- 整组是一个列表框：Tab 进入后用左右方向键在色块间移动（上下方向键不移动，排成网格时也一样）。
- `disabled` 时色块不可选，“自定义”不打开面板；面板开着时变成禁用，面板里的控件也一并禁用。

## 数据

```ts
type ColorSwatchesSize = "sm" | "md";

interface ColorSwatchesProps {
    /** 当前颜色；null 表示“自动”。受控，必填 */
    modelValue: string | null;
    /** 色板里的颜色（CSS 颜色字符串，比较时不分大小写）；必填 */
    colors: ReadonlyArray<string>;
    /** “自动”的文字；非空才显示“自动”色块。默认 "" */
    autoLabel?: string;
    /** “自动”色块填的颜色，任意 CSS 颜色（可以是 var() 或 oklch() 表达式）；默认 "" 即不填色 */
    autoColor?: string;
    /** “自定义”的文字；非空才显示“自定义”色块。默认 "" */
    customLabel?: string;
    /** 排成几列的网格；0 为一行、放不下换行。默认 0 */
    columns?: number;
    /** 色块尺寸；默认 "md" */
    size?: ColorSwatchesSize;
    /** 禁用；默认 false */
    disabled?: boolean;
    /** 整组的可访问名称；默认 "颜色" */
    label?: string;
}

interface ColorSwatchesEmits {
    /** 选中了另一个色块或在面板里取了色；“自动”为 null，取色面板发出小写 #rrggbb */
    (event: "update:modelValue", value: string | null): void;
}
```

没有插槽与 expose。未声明的 attrs 落在整组的根元素上。每个色块带 `data-color-swatch`：普通色块是小写的颜色值，另外两个是 `auto`、`custom`。

## 不支持

不支持多选、不支持透明度、不提供“清除”（要清除就提供“自动”）。色板的颜色和顺序由使用方给，组件不排序、不去重。
