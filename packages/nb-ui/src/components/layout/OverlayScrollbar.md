# OverlayScrollbar

挂在一个已有的滚动元素上的叠加滚动条：原生滚动条不画、不占宽度，一条半透明滑块（宽 `--scrollbar-w`，缺省 6px）叠在内容右缘；鼠标进到滚动元素所在的区域、正在滚动或拖着滑块时淡入，离开后等一会儿再淡出。时机与外观照 VS Code 的列表（[`docs/specs/workbench/views.md`](../../../../../docs/specs/workbench/views.md) 输出 12）。

和 `ScrollArea` 的差别：`ScrollArea` 自己建滚动容器、把内容包进去；本组件不包内容，只接到调用方已经有的滚动元素上——资源管理器的树既是滚动元素又是带键盘焦点的 `role="tree"`、虚拟列表直接读写它的 `scrollTop`，不能换成别的容器。

## 数据

```ts
type OverlayScrollbarProps = {
    /** 被滚动的元素，必填（可以是 null：还没挂上时不画）。与本组件同一个父元素，父元素要定位（relative 等）。 */
    target: HTMLElement | null;
};
```

没有 emits、slots、expose。未声明的 attribute 落在轨道元素上。

## 行为

- **接上**：`target` 换成一个元素时，给它加 `nb-ui-scrollbar-none`（原生滚动条不画、不占宽度，自成层叠上下文），在它的父元素上听指针进出，在它自己上听滚动，并观察它与它的直接子元素的尺寸（内容变高时滚动元素自己的尺寸可能不变）；换掉或卸载时全部撤掉、类名去掉。
- **摆放**：轨道比滑块宽 4px（缺省 10px），按滚动元素在父元素里的位置贴在它的右缘，高度等于它的可见高度；滑块宽 `--scrollbar-w`、靠右 2px，高度按可见比例、不短于 20px（几何与弹出列表的滑块共用 `utils/scrollbar-geometry`）。内容不溢出（多出不到 1px）时什么都不画。
- **显隐**：父元素里有指针、最后一次滚动之后 100ms 内、或正拖着滑块时显示。显示时 100ms 线性淡入；隐藏时先等 500ms 再 800ms 线性淡出；看不见时不接指针。系统减少动画时不过渡。
- **指针**：拖滑块按比例滚动（滑块走完剩余轨道等于内容滚完），用指针捕获，移出轨道也跟手；按在滑块以外的轨道上朝那一侧滚一页。按下不抢焦点、不开始选中文字。键盘滚动照原生，滚动时滑块同样出现。
- **颜色**：滑块是 `--text-main` 按 `--scrollbar-thumb-mix`、悬停 `--scrollbar-thumb-hover-mix`、拖动 `--scrollbar-thumb-active-mix` 混透明（缺省 32%、45%、55%）；没有轨道底色。

## 状态与边界

只有显示与隐藏两种样子；没有禁用、加载、出错状态。滚动元素的内容为空或不溢出时不画。

## 不支持

- 横向滚动条：只管竖向；横向溢出照原生（被 `nb-ui-scrollbar-none` 一并隐藏，需要横滚的元素不要用本组件）。
- 自定义时长；宽度与颜色只能经 `--scrollbar-*` token 统一调整，没有 prop。
- 显示区域不是父元素：要以更大的区域为准时，把滚动元素与本组件放进那个区域的直接子层。

## 注意事项

- 父元素必须定位，且是滚动元素的 `offsetParent`，否则摆放的坐标对不上。
- 滑块盖在内容上：行的悬停与选中底色会延伸到滑块下面，内容右缘不要放必须点到的控件，或给它留出轨道的宽度（缺省 10px）。
- `nb-ui-scrollbar-none` 让滚动元素自成层叠上下文：内容里的 `z-index` 只在它内部比较，不会盖过滑块，也不会盖过页面上的菜单。

## 隐藏通道理由

- `env:timer`：滚动停下的判断要一个短定时器（100ms）。滚动事件没有“结束”通知，`scrollend` 在惯性滚动与程序滚动上的触发并不一致；定时器在组件卸载时清掉。
