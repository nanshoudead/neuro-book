# 出处链接

把一个出处（`38.57` 或 `38.50—38.81`）写成可点的小号链接，点了在抽屉里打开那几段原文与前后文。查看器里任何地方的出处都用它，所以“出处一步到原文”（docs/specs/story/viewer.md 输出 19）只在一处实现。

## 数据

```ts
defineProps<{
    /** 出处原文，形状同查询结果里的 Ref。必填。 */
    refText: string;
}>();
```

没有 emits、slots、expose；attrs 透传到按钮上。

## 隐藏通道理由

`state:inject`：经 `useBook()` 取当前书的会话，调用 `openSource`。出处出现在几十种列表与卡片里，逐层把“打开原文”传成 props 或事件会让每个列表都多一条与自己无关的通道；抽屉属于书的外壳，会话就是外壳提供的那个入口。脱离书的外壳不能用（会抛错）。

## 注意事项

点击会 `stop` 冒泡：出处常嵌在可点的行里，点出处不应同时触发行的点击。
