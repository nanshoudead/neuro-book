# 读书方式的首次提示

问答页第一次切换“图当目录 / 全读”时弹出的模态对话框（docs/specs/story/viewer.md 的问答页）：标题“两种读书方式”，正文说你要切到哪一种，下面是两种方式在做法、优点、弊端上的对比表。确认键“知道了，切换”先停用 3 秒、按钮上显示倒计时，到时才能点；“先不切换”随时能点（倒计时只拦确认键），它和关闭窗口都不切换、也不算看过。

## 布局

用 nb-ui 的 `Dialog`（md 宽）：正文一句引导、一张三列对比表（行头加粗底、列“图当目录（默认）”“全读”），末尾一行灰字“只在第一次切换时提示”。窄屏时表格列等分，文字折行。

## 状态

`left`（本地）：打开时从 3 开始每秒减一，到 0 停；窗口关上就清掉计时。

## 数据

```typescript
defineProps<{open: boolean; target: "graph" | "full"}>();
defineEmits<{(event: "confirm"): void; (event: "cancel"): void}>();
```

`confirm` 在倒计时结束后点确认键发出；`cancel` 在点“先不切换”、关闭按钮、Esc 或点遮罩时发出。是否记住“看过了”由页面决定（`host/prefs.ts`）。

## 验证入口

问答页（`e2e/qa.e2e.ts`：第一次点模式按钮弹窗，倒计时结束前确认键停用，取消不切换，确认后切换且之后不再弹）。
