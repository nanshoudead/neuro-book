# 图上选中点的小卡片

关系图与全书图“按关联”里，点一下一个点只选中它，旁边浮出这张卡片（docs/specs/story/viewer.md 输出 27）：名字、类别与一句补充（出场次数），主按钮打开人物卡或连线说明，另一个按钮切换“只看周边”。它只负责显示和发事件，放在 `StoryNetwork` 的 `selected` 插槽里，跟着点移动、点被隐藏时消失都由图组件负责。

## 布局

宽 220 像素的面板：上面一行名字（过长截断）与关闭按钮，名字下面一行小字写类别与补充；下面两个小按钮。卡片里的指针按下与滚轮不传给画布，免得点按钮时画布当成点了空白处或开始平移。

## 数据

```ts
defineProps<{
    /** 点的显示名。必填。 */
    label: string;
    /** 类别的中文名。必填。 */
    kind: string;
    /** 补充的一句，例如“出场 120 次”；缺省不显示。 */
    detail?: string | null;
    /** 主按钮文字。必填。 */
    action: string;
    /** 现在是否“只看周边”。必填。 */
    neighborhood: boolean;
}>();
defineEmits<{
    /** 点了主按钮。 */
    open: [];
    /** 切换“只看周边”，带新的值。 */
    neighborhood: [boolean];
    /** 点了关闭：宿主取消选中。 */
    close: [];
}>();
```

没有 slots、expose；attrs 透传到根元素。
