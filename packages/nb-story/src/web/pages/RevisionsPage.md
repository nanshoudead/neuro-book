# 待确认页

对图的修订（docs/specs/story/viewer.md 输出 58、62）：“待确认”页签列出对不上的（先）与待确认的候选身份，“已处理”页签列出已确认、已驳回、后文已确认和用户自己的修订；来源筛选（全部、马甲核对、抽取候选、我的）。一项一张卡片（`RevisionCard`），确认、驳回、撤销、丢弃都经 `useRevise`；点卡片（或卡片上的一句话）在抽屉打开相关人物卡，抽屉里同一条候选高亮；从人物卡“这个对象的修订”跳来时只看这个对象的（可清除）。列表跟阅读位置走，页头写明。

## 数据

没有 props。

## 隐藏通道理由

- `state:inject`：经 `useBook()` 读阅读位置、打开抽屉、取走从人物卡跳来的对象筛选。
- `io:read`：页面自己取 `revisions.list`（待确认、对不上、已处理三个分页查询），参数随页签、来源与对象筛选变，由页面取最直接。
- `io:mutate`：确认、驳回、撤销、丢弃经 `useRevise` 写入，成功后换新数据。

## 注意事项

写入成功后 `book.refresh()` 换新数据，列表按数据版本重取，滚动与抽屉不变。
