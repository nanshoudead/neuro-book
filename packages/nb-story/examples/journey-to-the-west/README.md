# 示例：《西游记》全 100 回

用 nbstory 抽取管线抽出的《西游记》记忆图，可以直接导入，不用调用模型。原作明代，公有领域；原文取自维基文库《西遊記》（世德堂本系），整本转成简体。

- `xiyouji-graph.json.gz`：V9 记忆图，解压后 9 MB；原文、100 回的人物、称呼、说法、谁知道什么、情节、悬念、时间线都在里面。
- 抽取模型是 `gpt-6-luna`（OpenAI Chat 接口），2026-10-24 抽成。

## 导入

```bash
gunzip -c xiyouji-graph.json.gz > xiyouji-graph.json
nbstory import xiyouji-graph.json --title 西游记 --library ./xyj-library
nbstory books --library ./xyj-library
```

导入后书库里是 100 章、852 个对象、2,136 条说法、98 个秘密、387 个情节。后面的命令都加同一个 `--library ./xyj-library`（也可以不加 `--library`，导进默认书库）。

## 走读

```bash
# 孙悟空读到第 7 回时是什么样：称呼、神通、关系、秘密，不含之后的事
nbstory card 孙悟空 --at 7

# 谁知道什么：读到第 27 回，每个秘密谁知道、谁不知道，附“章.段”出处
nbstory knows --at 27

# 两个人之间的说法、一起出场的情节、互相知道的事
nbstory between 孙悟空 唐僧 --at 14

# 搜说法和原文：紧箍咒，读到第 20 回为止
nbstory search 紧箍咒 --at 20

# 网页查看器（秘密页、关系图、人物卡、时间线、原文、问答），打印登录链接
nbstory serve --library ./xyj-library --open
```

`--at` 限定阅读位置，之后的内容不出现。例如 `search 紧箍咒 --at 20` 只给第 14 回的两条说法和一段原文。

内置问答要先 `nbstory config init` 配模型，再 `nbstory ask "孙悟空知道戴在头上的是什么吗？" --at 14`。

- 前 7 回每回约 ¥0.15，全书平均每回约 ¥0.22；推断是越往后要送进模型的前文越多，没有逐回核对。
